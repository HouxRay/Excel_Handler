# 设置对话框中显示的路径与实际选择路径不一致，点"应用"后数据跳转

## 1. 实际行为
当前软件实际表现是什么？贴错误日志或截图。

1. 启动时选择路径：
   - JC：`D:\Excel_Hander\excel\2026-07-06-jc`
   - Excel：`D:\Excel_Hander\excel\副本7-6.xlsx`
   - Sheet：`6-29（3）`
2. 打开"设置"对话框，显示的是**错误路径**：
   - JC：`C:\Users\Admin\AppData\Local\Temp\claude_zip_ylkxx585\2026-07-06-jc`（临时解压目录）
   - Excel：`D:/My_app/test_excel/jc_example.xlsx`（历史残留路径）
   - Sheet：`4-17（2）`（历史残留）
3. **不修改任何设置**，直接点"应用"，软件数据立即跳转到设置中显示的路径下的文件，与启动时选择的内容不一致。

## 2. 预期行为
应该是什么样？

- 设置对话框中显示的路径应与当前软件实际使用的路径**一致**。
- 点击"应用"（未做任何修改）不应改变当前数据。
- 若用户使用 ZIP 启动，设置中应显示原始 ZIP 路径（而非临时解压目录）。

## 3. 复现步骤
1. 打开软件，选择任意路径启动（建议用 .zip 文件）
2. 进入主界面后点击"⚙️ 设置"
3. 观察设置中显示的路径与启动时选择的不一致
4. 不修改任何内容，点击"应用"
5. 软件数据跳转到错误路径下的文件

## 4. 运行环境
- 模式：HTML / 图片 / 北单：HTML（JC模式）
- 是否用 JSON 启动：是 / 否：否
- Excel 文件和 Sheet 名：启动时选 `副本7-6.xlsx` / `6-29（3）`，设置显示 `jc_example.xlsx` / `4-17（2）`

## 5. 影响范围
该 bug 影响哪些功能、哪些模式？是否阻塞工作？

- 严重阻塞：用户一旦进入设置并点"应用"，数据会切换到错误路径，且难以恢复。
- 影响所有模式（HTML/图片/北单）。
- 根因疑似：设置对话框从 QSettings 读取历史残留路径，而非主窗口当前实例路径；且 ZIP 解压后路径被存储为临时目录。
