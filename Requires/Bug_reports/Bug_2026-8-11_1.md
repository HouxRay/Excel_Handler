# Bug：表头序号 206 无法被软件读取（仅读到 201-205）

## 1. 实际行为
当前软件实际表现是什么？贴错误日志或截图。

输入：
- Excel：`test_excel\jc-bd.xlsx`
- JC 文件夹：`test_excel\2026-05-12-jc`
- Sheet：`sheet1`

该 Excel 的表头包含 201, 202, 203, 204, 205, 206 六个序号，每个序号后方有对应的模拟队伍名称。软件启动后，左侧/数据中**只能查到 201, 202, 203, 204, 205**，**206 无法被查看**。

## 2. 预期行为
应该是什么样？

206 应该与 201-205 一样被正常读取、显示，并可参与后续的填入/导出操作。

## 3. 复现步骤
1. 打开软件，选择 `test_excel\jc-bd.xlsx`（Sheet: sheet1）+ `test_excel\2026-05-12-jc`
2. 启动后查看数据/表头
3. 发现只有 201-205，206 缺失

## 4. 运行环境
- 模式：HTML / 图片 / 北单：HTML（JC 模式）
- 是否用 JSON 启动：是 / 否：否
- Excel 文件和 Sheet 名：`test_excel\jc-bd.xlsx` / sheet1

## 5. 影响范围
该 bug 影响哪些功能、哪些模式？是否阻塞工作？

- **恶性 bug**：表头解析逻辑漏读最后一个序号（206），导致该场比赛数据完全不可用
- 影响 HTML 模式的数据读取、填入、导出
- 疑似根因：`Excel_Handler.read_header_bases()` 或 `GetWriteInfo.get_tabel_info()` 的表头扫描逻辑在某种边界条件下提前终止，漏掉最后一项
