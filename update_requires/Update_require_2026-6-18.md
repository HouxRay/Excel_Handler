# 项目升级需求

> 本文档汇总了根据用户需求，对项目升级需求。

---
## 1. 概述
检测第三种数据模式"北单"，处理按队伍分类的北单文件。该模式只誊写比分，
不映射预测机构，目前该功能已经与主程序合并，需要检测功能是否符合预期需求。

## 2. 用户操作流程

1. 启动 -> 弹出选择路径器，填写如下4项：
    - Excel 文件（必选）
    - BD HTML 文件夹 （可选，用于北单模式，注：BD HTML 文件夹和 HTML 文件夹不能同时为空）
    - HTML 文件夹 （可选，用于正常模式，注：BD HTML 文件夹和 HTML 文件夹不能同时为空）
    - JSON 文件 （可选）
    - Sheet 选择 （必选）
2. 点击确认 -> 打开主窗口，如果只有BD HTML 文件夹，且 HTML 文件夹为空，则默认以北单模式运行。若 HTML 文件夹不为空，则默认以正常模式运行。BD HTML 文件夹和 HTML 文件夹哪个为空，则相对应的模式默认关闭切不可选。
3. 左侧列表显示从 Excel 读取的比赛编号（如"北单1 队伍A VS 队伍B"）
4. 点击一个比赛 → 右侧 6 列表格：
   - 第 0 列：行号（1~N，不可编辑）
   - 第 1 列：队伍名（字符串，不可编辑）
   - 第 2~5 列：比分输入框（可编辑，空值允许）
   - 默认显示 30 行空行
5. 填入数据 → 点击"保存" → 数据存入内存
6. 点击"导出" → 按编号找到 Excel 对应列，纵向追加写入第一个空行
7. 点击"排序" → 统计每个比分出现频率，写入 Excel 第 84 行
8. 点击"导出JSON" → 保存到 json/bd_YYYY-MM-DD.json
9. 如果JSON路径不为空，则加载JSON → 数据还原到对应比赛的表格中

## 界面设计
| 区域 | 内容 | 说明 |
|------|------|------|
| 顶部按钮 | HTML / 图片 / **北单** | 三模式切换，高亮当前模式 |
| 左侧列表 | 北单1 队伍A VS 队伍B | 每行一个比赛，单选 |
| 右侧表格 | 6 列：序号、队伍、比分1~4 | 最少 30 行 |

主工具栏按钮：保存、导出、排序、导出JSON、清空

## 4. 数据流
- **数据来源**：BD HTML 文件夹中的 `北单N.html` 文件（递归扫描子目录）
- **存储结构**（内存）：
```python
self.bd_data_storage = {
    "北单1 队伍A VS 队伍B": {
        "code": "1",
        "home": "队伍A",
        "away": "队伍B",
        "scores": [["01","02","03","04"], ["02","01","00","00"]]
    }
}
```

保存 → 只写入内存，不写 Excel（导出才写）
导出JSON → json/bd_YYYY-MM-DD.json，下次启动读取
导出Excel → 找到编号列的第一个空行开始写

## 5.详细规则
1. Excel 列匹配：扫描第一行，正则 ^(北单)?(\d+)$ 匹配纯数字或"北单+数字"
2. HTML 文件匹配：递归扫描 BD 文件夹，从文件名正则 北单(\d+) 提取编号，按 int 值匹配
3. 表格显示：至少有 30 行（空行补足），已有数据的行显示实际数据
4. 导出写入：验证比分值(需要验证比分是否为2位数，类似 validate_value功能，验证不通过提示用户)，不经过映射表和 MATCH_DICT
5. 排序统计：只统计纯 2 位数字比分
6. 保存：过滤空行再存储
7. 填入数据：目前不使用，后续加入AI功能后再启用

## 6. 边界情况
|场景|预期行为|
|------|------|
|只选 BD 文件夹，不选 HTML 文件夹|启动正常，HTML 按钮不亮，点击时提示"未设置 HTML 路径"|
|只选 HTML 文件夹，不选 BD 文件夹|启动正常，BD 按钮不亮，点击时提示"未设置 BD HTML 路径"|
|同时选 BD 文件夹和 HTML 文件夹|启动正常，正常模式启动，北单模式默认开启，点击按钮转换|
|BD HTML 在嵌套子目录中|递归搜索，能找到|
|导出后切换比赛再切回来|表格保持 30 行，已有数据不丢|
|JSON 加载|按 label 匹配恢复 scores|
|排序时遇到空行或无效字符串|跳过，提示，不报错|
