# ExcelHandler · Excel 数据誊写工具

一个基于 **PyQt5** 的桌面应用，用于把各类来源的数据按映射关系批量写入 Excel 工作簿的指定位置。

## 简介

**ExcelHandler** 是一个桌面数据誊写工具：读取目标 Excel 的**表头、行标识与编号列**，
算出每个数值应写入的单元格坐标，再把来自网页、图片或结构化数据源的内容写入这些位置。

主要能力：

- 读取 Excel 结构并计算写入坐标；
- 从网页（HTML）、图片、结构化数据三类来源提取数据；
- 通过**白名单校验**保证只写入已存在的编号与位置；
- 后台线程写入、数据统计排序、JSON 备份与恢复。

## 功能特性

### 数据源与编辑

| 功能 | 说明 |
|---|---|
| **双数据源独立配置** | 两套数据源各自独立的 Excel / JSON / Sheet 配置，互不影响 |
| **三种数据模式** | 网页 / 图片 / 结构化数据，顶部按钮一键切换 |
| **分类导航 + 表格编辑** | 左侧单选切换分类，右侧表格直接编辑数值；空格或反引号自动转为 `0` |
| **路径持久化** | 路径与 Sheet 记入 `config.ini`，下次启动自动预填；支持不重启切换数据源 |
| **网页预览** | 内嵌 WebEngine 查看原始页面，日期高亮（按北京时区自动检测，可手动切换） |

### 自动提取

| 功能 | 说明 |
|---|---|
| **AI 提取** | 调用兼容 OpenAI 接口的模型从网页提取数据，**预览勾选后**才填入 |
| **图片识别双通道** | **原生视觉**（默认，快）或 **本地 OCR**（可离线），共用同一提示词与解析器 |
| **图片输入** | 选择图片、从剪贴板粘贴、拖拽进窗均可；剪贴板位图自动归档 |
| **批量提取** | 遍历文件夹内全部网页文件批量处理（强制先配白名单、**不覆盖已有值**、可取消重试） |
| **结果留档与复用** | 结果存 `json/ai/<日期>/`，可按日期与分类筛选复用历史结果 |

### 导出与维护

| 功能 | 说明 |
|---|---|
| **导出写入** | 后台线程写入 Excel，不阻塞界面；白名单校验失败会逐条提示 |
| **批量导出** | 批量提取的结果**汇总后一次写入**，避免反复开关工作簿 |
| **数据排序** | 统计各编号下数值出现频次，写入 Excel 指定区域 |
| **JSON 备份/恢复** | 导出为按编号组织的 JSON，可二次导入继续编辑 |
| **日志系统** | 文件日志 + 界面日志框，便于事后追查 |

## 环境要求

| 依赖 | 用途 |
|---|---|
| Python 3.10+ | 运行时 |
| PyQt5 / PyQtWebEngine | 界面与网页预览 |
| openpyxl | 读写 Excel |
| openai | 模型调用（OpenAI 兼容 SDK） |
| pypinyin | 中文排序与匹配 |
| html2text | HTML → Markdown（供模型读取） |
| rapidocr_onnxruntime | 本地 OCR（可选，未安装则只用原生视觉） |

## 快速开始

```bash
# 1. 安装依赖
pip install PyQt5 PyQtWebEngine openpyxl openai pypinyin html2text rapidocr_onnxruntime

# 2. 运行
python main.py
```

> 首次启动会弹出路径选择对话框，按提示选择网页目录、Excel 文件与 Sheet 即可。

## 使用流程

1. **启动** → 路径选择对话框（两套数据源分组）
2. **选数据源** → 网页目录、Excel 文件、可选 JSON、目标 Sheet
3. **编辑** → 左侧切分类，右侧改数值
4. **自动提取**（可选）→ `🤖 AI 填入` 选新结果 / 粘贴图片 / 历史记录；或 `⚡ 一键运行` 批量处理整个文件夹
5. **写入** → `📤 导出`（当前分类）或 `📤 一键导出`（批量汇总）
6. **排序 / 备份** → `📊 排序` 统计频次，`📝 写入JSON` 留档

操作按钮按颜色分三行：

- 🟢 **绿色**：重新选择路径 · 清空（二次确认）· 退出并打开 Excel 目录
- 🟠 **橙色**：填入数据 · 刷新 · 设置 · AI 填入 · 一键运行
- 🔵 **蓝色**：打开 · 保存 · 导出 · 排序 · 写入 JSON · 一键导出

## 核心模块

| 模块 | 职责 |
|---|---|
| `Excel_Info` | 把"行标识 + 编号"换算成 Excel 的（行, 列），是写入正确性的核心 |
| `Excel_Writer` | 统一写入入口；校验值合法性，支持单格 / 批量 / 字典写入与一次保存 |
| `Name_Matcher` | 处理"文件名与 Excel 行名不完全一致"的情况 |
| `ai_handler` | 串起 配置 → 提示词 → 请求 → 解析 → 对齐 → 留档 的完整链路 |
| `worker` | 把写入放到后台线程，界面不阻塞 |
| `exporter` | 先把"要写什么"收集成操作列表，再一次性提交，支持排序统计 |

## 数据与隐私

- **API Key 加密保存**在本地 `config.ini`，不以明文存放在仓库中。
- 模型调用的**输入内容**（网页转换后的文本或图片）会发送到所配置的服务商，
  请自行确认其数据使用政策。
- 运行结果留在本地：`json/ai/<日期>/`（提取留档）、`pic/<日期>/`（图片归档）、`logs/`（日志）。
